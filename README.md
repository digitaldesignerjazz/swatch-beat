# Swatch Beat

**Rhythm, Time & Beats through Swatch Internet Time**

This repository explores the intersection of **music beats**, rhythm, and **time systems**, using **Swatch Internet Time** (also known as .beat) as the primary time reference.

## What is Swatch Internet Time?

Swatch Internet Time divides the day into 1000 ".beats". 
- One day = 1000 .beats
- @000 = 00:00 UTC (midnight)
- @500 = 12:00 UTC (noon)
- No time zones — universal time for everyone

This repo starts at **@000**.

## Purpose

- Create and document beats (musical and rhythmic)
- Experiment with time-based creative systems
- Build tools, prompts, and projects that use .beat as a universal timestamp
- Connect music production with alternative time concepts

## Current Focus
